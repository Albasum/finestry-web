                in screen: CGRect) -> Board {
  let sizes = probe(windows)
  let board = reconcile(sizes, screen)
  return board.snappedToGrid()
}

    anchor: CGFloat, step: CGFloat) -> CGFloat {
  anchor + ((v - anchor) / step).rounded(.down) * step

The problem

Other tools guess the size. Apps refuse it.

Terminal snaps to its character grid. Some apps won't shrink below a minimum. Ask for a size an app won't take and you get crooked gaps and overlapping edges.

Finestry measures each app first: its real minimum and the steps it resizes in. Then it plans the whole layout around those numbers, so the first result is already right.

How it works

Measure once. Place once.

01

Probe

One quick probe per window finds the sizes each app really accepts. The result is cached per app and version.

02

Reconcile

Plain arithmetic on the real sizes: snap to each app's grid, fill the screen and keep every gap identical.

03

Apply

A final check covers minimums, screen edges, overlaps and gaps. Then only the windows that change are moved, once.

FAQ

Questions, answered.

Which Macs does it run on?

Any Mac running macOS 14 Sonoma or later.

Why does it ask for Accessibility access?

macOS only lets an app move and resize other apps' windows through the Accessibility permission. Finestry needs it to place your windows.

What do crash reports include?

Reports are only sent with your consent. Logs never include window titles, and you can also send a report yourself from the menu.

Is it a subscription?

No. Finestry will be a one-time purchase, and free during the beta.

Who answers my messages?

I do. Finestry is a one-person project, so please be patient if a reply takes a few days.
